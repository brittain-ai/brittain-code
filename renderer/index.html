INTEGRATIONS (MCP)

          
Connect external tool servers (browsers, databases, APIs) over the Model Context Protocol. Servers are defined in a JSON config file; restart the app after editing it.

          

            
            
          


          

            
            

              ⚠ Trust warning. MCP servers are third-party code that runs on your machine and can read files, reach the network, or take actions outside this app. By default every MCP call waits for your approval — even when AUTO-APPROVE is on — so you can inspect each one. Turning this on removes that check and lets any connected server act automatically. Only enable it for servers you fully trust and have configured yourself.
