## Missions

`/mission [n] <goal>` runs a visible, persisted, bounded coding mission with planner/coder/verifier roles. It records its goal, project, models, phase, latest evidence, and final report under the application-data directory, so you can inspect progress with `/mission status` and cancel with `/mission stop`. One mission runs at a time; closing the app marks an active mission interrupted rather than silently resuming it. Missions keep the same tool permissions and approval rules as ordinary Code mode.

`/loop` remains the simple single-model loop, and `/orchestrate` remains the planner/coder/verifier delegation path. Orchestrator and coder loops now pass an explicit handoff between attempts, so a coder retry starts from what the previous attempt actually did instead of re-exploring from scratch.

## Undo and auto-branch

Every Code-mode run in a Git repo now takes a silent checkpoint first, so **UNDO RUN** restores the working tree even if you never committed — and UNDO itself snapshots first, so it is also undoable. Optional auto-branch moves agent work onto a generated `brittain/<slug>` branch before anything is touched.

## MCP

MCP tool calls can now be auto-approved through a dedicated, off-by-default `mcpAutoApprove` setting, gated behind an explicit disclaimer in Settings. The default is unchanged and deliberate: MCP servers are third-party code, so every call waits for approval even when AUTO-APPROVE is on.

## Brittainmark v3

The offline benchmark is now a deterministic evaluation suite with no LLM judge — hidden graders live outside the scratch directory, so runs are scored on what the code actually does.

- **Seven versioned tasks** across JavaScript, Python, and TypeScript: checkout arithmetic, atomic inventory rollback, debugging with green visible tests, deterministic snapshot/resume simulation, a leased durable outbox, ML data-leakage traps, and a paginated typed API sync.
- **Rebalanced scoring** — correctness 80, safety 10, reliability 7, efficiency 3 — with catastrophic runs zeroed rather than floored.
- **Automated batch runs**: `node benchmark/run.js --models 'local:*' --tasks all` creates fixtures, drives the tool loop, saves chats, and grades every run.
- **Provider adapters** for Ollama, OpenAI, and Anthropic, so local models can be compared against hosted ones. Benchmark-only — the app itself remains Ollama-compatible.
- **Richer reports**: leaderboard separated from archived runs, model-by-task matrix, and telemetry-backed timing. `/best` ranks your installed models from those results.
- Solo runs are no longer mislabeled as team runs; team scoring requires an explicitly recorded team run or a real orchestration in the telemetry.

## Cross-platform

Windows fixes, and system instructions no longer assume macOS. `npm run dist:all` now builds both Mac architectures plus the Windows installer.

## Other changes

- Tools consolidated from 60 to 51 entries, with the model-degradation guards added in 1.3.15 hardened and covered by unit tests.
- New slash commands: `/context` (exactly what will be sent next turn, with per-message tokens and eviction flags), `/best`, `/graph`, and `/mcp`.
- README updated for MCP, degradation detection, undo/auto-branch, Windows support, and Brittainmark v3.
